# Лабораторная работа № 7. Функции и автоматические проверки

Вариант 8 — отобрать числа, модуль которых не больше заданного порога. Функция `select_numbers()` возвращает новый список с исходным порядком и повторами.

## Запуск

Откройте терминал в папке `lab07`. В Windows вместо `python3` можно использовать `py`.

| Команда | Назначение |
| --- | --- |
| `python3 main.py` | Продемонстрировать обязательные функции и индивидуальный вариант |
| `python3 test_functions.py` | Выполнить автоматические проверки через `assert` |

При запуске `main.py` введите целое число, строку целых чисел через пробел, произвольный текст и неотрицательный целый порог. Для пустого списка нажмите Enter на втором шаге.

## Проверки

Все 26 автоматических проверок прошли на Python 3.12.14. Дополнительно проверены два запуска программы с вводом и импорт модулей без вывода.

| Проверка | Ввод | Ожидаемый результат | Фактический результат |
| --- | --- | --- | --- |
| Основной запуск | `-507` → `-5 0 2 5` → `  ПРИВЕТ   Мир  ` → `2` | Сумма цифр 12, среднее 0.5, «привет мир», выборка `[0, 2]` | Сумма цифр 12, среднее 0.5, «привет мир», выборка `[0, 2]` |
| Пустой запуск | `0` → пустой список → три пробела → `0` | Сумма цифр 0, «Нет данных», пустой текст, выборка `[]` | Сумма цифр 0, «Нет данных», пустой текст, выборка `[]` |
| Границы отбора | `[-3, -2, -1, 0, 1, 2, 3]`, порог 2 | `[-2, -1, 0, 1, 2]` | `[-2, -1, 0, 1, 2]` |

### Намеренная ошибка

В копии `functions.py` условие `abs(number) <= threshold` временно заменено на `abs(number) < threshold`. При пороге 2 неправильная функция исключает число 2. Проверка `assert select_numbers([-5, 0, 2, 5], 2) == [0, 2]` завершилась с `AssertionError`. После запуска с исправным условием весь набор проверок снова прошёл.

### Дополнительное задание

Проверки `is_palindrome()` написаны перед реализацией функции. Она игнорирует регистр и обычный пробел. Пунктуация и табуляция участвуют в сравнении. Для пустой очищенной строки результат — `False`.

## Пояснения к защите

- `return` передаёт значение вызывающему коду, где его можно сохранить, проверить или использовать в другом вычислении. `print()` отображает результат в терминале.
- `number` в определении `sum_digits(number)` — параметр, который получает значение при вызове. `total` — локальная переменная, которая создаётся внутри вызова.
- Условие `if __name__ == "__main__"` запускает ввод и вывод при прямом запуске `main.py`. При импорте доступны определения функций.
