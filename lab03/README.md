# Лабораторная работа № 3. Условия и логические выражения

Вариант 8 — заполнение группы. При заполнении от 0 до 39% выводится «Есть места», от 40 до 79% — «Группа набирается», от 80 до 100% — «Почти заполнена».

## Запуск

Откройте терминал в папке `lab03` и запустите нужную программу. В Windows вместо `python3` можно использовать `py`. Каждое значение вводится отдельной строкой. Для дробных чисел используйте точку.

| Команда | Назначение |
| --- | --- |
| `python3 minimum.py` | Найти минимум трёх целых чисел |
| `python3 calculator.py` | Выполнить арифметическую операцию |
| `python3 point.py` | Проверить принадлежность точки прямоугольнику |
| `python3 variant.py` | Определить категорию заполнения группы |
| `python3 leap_year.py` | Проверить, является ли год високосным (дополнительное задание) |

## Пояснения к защите

- В `minimum.py` первое число подходит, если оно меньше или равно обоим остальным. Если эта проверка не прошла, достаточно сравнить второе и третье числа. Оператор `<=` учитывает равенство, поэтому при одинаковых минимумах результатом будет их общее значение.
- В калькуляторе выполняется первая подходящая ветвь. Нулевой делитель проверяется только после выбора операции деления. Результат выводится с двумя знаками после точки.
- В `point.py` используется `and`, поскольку ограничения для `x` и `y` должны выполняться одновременно. Операторы `<=` включают стороны и углы прямоугольника.
- В `variant.py` используется `or`, поскольку для ошибки достаточно одного нарушения границ. Проверка диапазона выполняется первой. Затем пороги проверяются по возрастанию: если число меньше 80 и условие «меньше 40» уже не выполнилось, оно попадает в категорию 40–79.
- В `leap_year.py` через `or` объединены два случая високосного года. Через `and` проверяется второй случай: год делится на 4 и при этом не делится на 100.
