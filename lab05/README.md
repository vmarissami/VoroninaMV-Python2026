# Лабораторная работа № 5. Обработка строк

Вариант 8 — вывести слова, содержащие ровно одну кириллическую букву «а», и подсчитать их количество.

## Запуск

Откройте терминал в папке `lab05` и выполните нужную команду. В Windows вместо `python3` можно использовать `py`. Каждая программа читает одну строку.

| Команда | Назначение |
| --- | --- |
| `python3 normalize.py` | Нормализовать пробелы и подсчитать слова |
| `python3 palindrome.py` | Проверить палиндром обратным срезом |
| `python3 replace.py` | Заменить двоеточия дефисами и подсчитать замены |
| `python3 variant.py` | Вывести слова с одной буквой «а» |
| `python3 palindrome_loop.py` | Проверить палиндром циклом (дополнительное задание) |

## Пояснения к защите

- Строки в Python неизменяемы. Методы `lower()`, `strip()` и `replace()` возвращают результат, который можно сохранить в переменную. В `replace.py` двоеточия сначала подсчитываются в исходной строке.
- Слово в нормализации — непустая часть, которую вернул `split()`. Подстрока может находиться внутри слова. Программа варианта использует `count("а")` для подсчёта буквы внутри каждого очищенного слова. Повторяющиеся слова выводятся при каждом совпадении.
- Правила пунктуации влияют на ответ. В нормализации знаки остаются частью слова. В варианте удаляются только символы `.,!?;:` по краям слова. При проверке палиндрома сравниваются все знаки препинания и пробельные символы, кроме обычного пробела.
- В дополнительном задании цикл сравнивает пары символов от краёв очищенной строки к середине. Достаточно пройти половину её длины, поскольку каждая пара проверяется один раз.
