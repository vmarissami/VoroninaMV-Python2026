# Лабораторная работа № 4. Циклы, счётчики и накопители

Вариант 8 — подсчёт количества и суммы чисел с модулем больше 5.

## Запуск

Откройте терминал в папке `lab04`. Вводите каждое число отдельной строкой. В Windows вместо `python3` можно использовать `py`.

| Команда | Назначение |
| --- | --- |
| `python3 range_numbers.py` | Вывести числа между заданными границами включительно |
| `python3 statistics.py` | Найти сумму, количество положительных чисел и максимум |
| `python3 positive_input.py` | Запросить положительное число, вывести квадрат и количество отклонённых попыток |
| `python3 variant.py` | Подсчитать количество и сумму чисел с модулем больше 5 |
| `python3 prime.py` | Проверить число на простоту (дополнительное задание) |

## Суммирование чисел от 1 до 4

Перед циклом `for number in range(1, 5)` накопитель `total` равен нулю. На каждой итерации выполняется `total += number`.

| Итерация | `number` | `total` до итерации | `total` после итерации |
| ---: | ---: | ---: | ---: |
| 1 | 1 | 0 | 1 |
| 2 | 2 | 1 | 3 |
| 3 | 3 | 3 | 6 |
| 4 | 4 | 6 | 10 |

## Пояснения к защите

- У `range(a, b)` правая граница исключается, а шаг по умолчанию равен 1. Поэтому при `a >= b` такой диапазон пуст. В программе шаг равен 1 или −1, а граница `b + step` позволяет вывести `b`. При равных границах получается одна итерация. Цикл завершается после перебора всех значений диапазона.
- В статистике первое значение используется как начальный максимум. Это даёт правильный результат даже для потока, состоящего только из отрицательных чисел. Первое число обрабатывается до цикла, а оставшиеся `n - 1` читаются в цикле.
- В `positive_input.py` условие цикла проверяется после каждого нового ввода. Как только введено положительное число, условие становится ложным. Если пользователь продолжает вводить нули или отрицательные числа, программа продолжает запрашивать ввод.
- В варианте за один проход обновляются счётчик и сумма. Значения −5 и 5 пропускаются, а −6 и 6 учитываются. В контрольном наборе подходят −12, 10, 15 и 20. Их четыре, сумма равна 33.
- При проверке простоты делитель увеличивается на единицу. Цикл завершится при первом найденном делителе или когда квадрат текущего делителя превысит число. Если число составное, в паре его множителей хотя бы один не превышает квадратного корня из числа.
