# Лабораторная работа № 9. Вложенные списки и таблицы

Вариант 8 — уменьшить каждый отрицательный элемент матрицы на 2. Нули и положительные элементы сохраняются.

## Запуск

Откройте терминал в папке `lab09`. В Windows вместо `python3` можно использовать `py`.

| Команда | Назначение |
| --- | --- |
| `python3 main.py` | Ввести матрицу, рассчитать суммы, вывести диагональный узор и преобразовать матрицу |
| `python3 test_table.py` | Выполнить автоматические проверки |
| `python3 recursion_example.py` | Сравнить рекурсивное и итеративное вычисления факториала для чисел от 0 до 20 |

Для основного запуска введите число строк и число столбцов отдельно. Затем вводите каждую строку матрицы целыми числами через пробел. Если длина строки отличается от заданной, программа запросит ту же строку повторно. После вывода сумм введите размер диагонального узора.

## Проверки

Все проверки прошли на Python 3.12.14.

## Рекурсия

Базовый случай — `factorial(0) == 1`. На каждом следующем вызове аргумент уменьшается на единицу. После достижения нуля вызовы возвращают результаты в обратном порядке.

| Вызов | Действие | Возвращаемое значение |
| --- | --- | ---: |
| `factorial(3)` | `3 * factorial(2)` | 6 |
| `factorial(2)` | `2 * factorial(1)` | 2 |
| `factorial(1)` | `1 * factorial(0)` | 1 |
| `factorial(0)` | Базовый случай | 1 |

Порядок возвратов: 1, 1, 2, 6. Для всех 21 целых чисел от 0 до 20 результат итеративной функции совпал с результатом рекурсивной.

## Пояснения к защите

- У матрицы 2×3 две суммы строк и три суммы столбцов. Такой пример выявляет ошибки, при которых одна и та же граница используется для обхода строк и столбцов. `zip(*matrix)` группирует элементы с одинаковым индексом столбца.
- Запись `[[0] * columns] * rows` повторяет ссылку на одну внутреннюю строку. Изменение одной ячейки становится видно и через другие строки. В диагональном узоре список для каждой строки создаётся отдельно.
- `matrix.copy()` создаёт новый внешний список, сохраняя ссылки на старые строки. Конструкция `[row.copy() for row in matrix]` копирует и строки. В `transform()` каждая строка результата создаётся отдельно, поэтому исходная таблица сохраняется.
