# Лабораторная работа № 10. Текстовые файлы и обработка ошибок

Вариант 8 — сумма элементов первой строки матрицы. На контрольных данных результат равен `1 + (-2) + 3 = 2`.

## Запуск

Откройте терминал в папке `lab10`. В Windows вместо `python3` можно использовать `py`.

| Команда | Назначение |
| --- | --- |
| `python3 main.py` | Проверить ввод размера, прочитать матрицу, записать отчёт и экспортировать матрицу в CSV |
| `python3 test_files.py` | Запустить проверки с файлами во временной папке |

Размер, который запрашивается при запуске, служит отдельной демонстрацией проверки ввода. Размеры для обработки матрицы берутся из заголовка файла. Файлы ищутся рядом с `main.py`. CSV содержит строки исходной матрицы без заголовка размеров.

## Формат входного файла

`matrix.txt` сохраняется в UTF-8. На первой строке записываются два положительных целых числа — число строк и столбцов. Далее следуют строки данных с целыми числами через пробельные символы. Число строк и элементов должно соответствовать заголовку. Пустые и лишние строки считаются ошибкой. Один перевод строки после последней строки допустим.

Контрольный файл:

```text
2 3
1 -2 3
4 0 -6
```

Результат в `report.txt`:

```text
Суммы строк: 2 -2
Суммы столбцов: 5 -2 -3
Результат варианта: 2
```

## Проверки

Проверки выполнены на Python 3.12.14. В таблице `⏎` обозначает перевод строки.

| Вход или ситуация | Ожидаемый результат | Фактический результат |
| --- | --- | --- |
| Ввод размера: `abc`, `0`, `-2`, `3` | Ошибка целого числа, два сообщения о неположительном числе, принят размер 3 | Совпало |
| `1 2 ⏎ 7 -1 ⏎` | `[[7, -1]]` | `[[7, -1]]` |
| `1 1 ⏎ 0` | `[[0]]` | `[[0]]` |
| Пустой файл | `ValueError`, строка 1 | `ValueError`, строка 1 |
| Заголовки `0 3` и `1 x` | `ValueError`, строка 1 | `ValueError`, строка 1 |
| `1 2 ⏎ 1` и `1 2 ⏎ 1 x` | `ValueError`, строка 2 | `ValueError`, строка 2 |
| `1 1 ⏎ 1 ⏎ 2` и строка данных с дополнительной пустой строкой после неё | `ValueError`, строка 3 | `ValueError`, строка 3 |
| `2 1 ⏎ 1 ⏎` | `ValueError`, строка 3 | `ValueError`, строка 3 |
| Пустая строка вместо строки данных | `ValueError`, строка 2 | `ValueError`, строка 2 |
| Нет входного файла | `FileNotFoundError` в функции, сообщение об отсутствующем файле при запуске | Совпало |
| Файл содержит недопустимый байт UTF-8 | Сообщение об ошибке кодировки | Сообщение об ошибке кодировки |
| Вместо входного файла подставлена папка | Сообщение об ошибке чтения | Сообщение об ошибке доступа |
| Вариант для матриц `[[1, -2, 3], [4, 0, -6]]`, `[[7]]` и `[]` | `2`, `7`, `0` | `2`, `7`, `0` |
| Экспорт и повторное чтение через `csv.reader` | `[["1", "-2"], ["0", "6"]]` | `[["1", "-2"], ["0", "6"]]` |

Отдельная проверка старого отчёта: во временной папке сохранила в `report.txt` строку «Предыдущий отчёт», а в `matrix.txt` записала заголовок `1 2` и строку `1 x`. После запуска программа сообщила об ошибке формата в строке 2. Побайтовое сравнение отчёта с сохранённой копией подтвердило полное совпадение.

## Пояснения к защите

- Ошибка формата возникает, когда файл удалось прочитать, но данные не соответствуют заданной структуре. Ошибки доступа связаны с открытием, чтением или записью файла. Ошибка UTF-8 обрабатывается перед `ValueError`, поскольку `UnicodeError` наследуется от него.
- Отчёт открывается для записи только после чтения всей матрицы и вычисления результатов. Иначе открытие в режиме записи могло бы стереть прежний отчёт до обнаружения ошибки во входе.
- Модуль `table.py` содержит функции из задания № 9. Он подготовлен по условиям этой работы, поскольку готового файла из неё в рабочей папке не было.
- Экспорт использует `csv.writer`, который обрабатывает разделители и кавычки по правилам CSV.
