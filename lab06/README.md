# Лабораторная работа № 6. Списки и обработка наборов данных

Вариант 8 — отбор целых чисел от 10 до 20 включительно. Программа сохраняет порядок и повторы в выборке, подсчитывает её размер и сумму и выводит отсортированную копию.

## Запуск

Откройте терминал в папке `lab06`. Введите целые числа одной строкой через пробел. Для пустого ввода нажмите Enter. В Windows вместо `python3` можно использовать `py`.

| Команда | Назначение |
| --- | --- |
| `python3 statistics.py` | Рассчитать количество, сумму, минимум, максимум и среднее |
| `python3 transform.py` | Создать список, в котором отрицательные числа заменены модулями |
| `python3 positions.py` | Найти все индексы максимального числа |
| `python3 variant.py` | Отобрать числа от 10 до 20 и отсортировать копию выборки |
| `python3 unique.py` | Удалить повторы в порядке первого появления (дополнительное задание) |

## Пояснения к защите

- Метод `append()` добавляет элемент в конец списка и увеличивает его длину. Присваивание по индексу заменяет элемент на уже существующей позиции.
- В `transform.py` каждый модуль добавляется в отдельный список `transformed`. Например, после обработки `-2 0 5 -2` исходный список по-прежнему равен `[-2, 0, 5, -2]`, а новый — `[2, 0, 5, 2]`.
- Функция `sorted()` возвращает новый список, поэтому порядок исходной выборки сохраняется. Метод `sort()` меняет порядок в самом списке и возвращает `None`.
- При поиске позиций максимума `enumerate()` выдаёт индексы с нуля в порядке обхода. Проверка на пустой список выполняется до вызова `max()`.
- В дополнительном задании очередное значение добавляется только при первом появлении. Проверка выполняется по уже собранному списку без множества.
