## Ручной расчёт заказа

Для заказа «Фотопечать» Анна Соколова заказала 8 малых фотографий по 15.50 руб. и 3 большие по 42.00 руб. Доставка стоит 35.00 руб., внесено 350.00 руб.

| Показатель | Расчёт | Ожидаемое значение |
| --- | --- | --- |
| Малые фотографии | 8 × 15.50 | 124.00 руб. |
| Большие фотографии | 3 × 42.00 | 126.00 руб. |
| Товары без доставки | 124.00 + 126.00 | 250.00 руб. |
| Общая сумма | 250.00 + 35.00 | 285.00 руб. |
| Общее количество | 8 + 3 | 11 шт. |
| Сдача | 350.00 − 285.00 | 65.00 руб. |

При скидке 10% стоимость товаров уменьшается на 250.00 × 10 / 100 = 25.00 руб. Итог с доставкой составляет 250.00 − 25.00 + 35.00 = 260.00 руб. Сдача составляет 90.00 руб.

## Пояснения к решениям

- `input()` возвращает строку. Сложение двух строк объединяет их, поэтому в фрагменте А строки `"2"` и `"3"` преобразуются в `int` перед сложением. В фрагменте Б возраст тоже преобразуется в `int`, чтобы к нему можно было прибавить единицу. Дробные величины преобразуются с помощью `float()`.
- Умножение и деление выполняются перед сложением. В фрагменте В скобки позволяют сначала найти сумму всех трёх чисел, а затем разделить её на три.
- При обмене временная переменная сохраняет значение первой аудитории до того, как в него записывается вторая. Затем сохранённое название записывается во вторую переменную.
- Формат `:.2f` выводит часы и денежные значения с двумя знаками после точки. Сдача округляется до копеек. Прибавление положительного нуля после округления убирает отрицательный знак у нулевой сдачи, который мог появиться из-за погрешности дробных вычислений.
