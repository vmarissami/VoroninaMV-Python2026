# Лабораторная работа № 12. План туристических маршрутов

**Автор — Воронина М. В.**  
**Вариант — 8**

Консольная программа ведёт список маршрутов, ищет по названию и считает суммарную протяжённость. Длина задаётся в целых километрах. Статус показывает, пройден ли маршрут.

## Запуск

Проверено на Python 3.12.14. Откройте терминал в распакованной папке `lab12` и выполните команды. На macOS вместо `python` можно использовать `python3`, а в Windows — `py`. Для работы достаточно стандартной библиотеки.

```text
python main.py
python -m unittest -v test_logic test_storage
```

В меню доступны просмотр, добавление, поиск, изменение статуса, удаление, статистика, сохранение и выход. Команда 7 сохраняет список сразу. Команда 8 предлагает сохранить его перед выходом.

## Данные

Файл `data.json` расположен рядом с `main.py`. Это список JSON-объектов в UTF-8. У каждой записи есть пять обязательных полей.

| Поле | Смысл и допустимое значение |
| --- | --- |
| `id` | Уникальное положительное целое число |
| `title` | Название маршрута, непустое после удаления краевых пробелов |
| `category` | Категория, непустая после удаления краевых пробелов. При подсчёте сравнивается с учётом регистра |
| `amount` | Длина маршрута в целых километрах, от нуля |
| `completed` | Логическое значение `true` или `false` |

В архиве четыре вымышленные записи. Ручной расчёт для образца даёт 4 маршрута, из них 2 пройдены и 2 запланированы. Общая длина равна 8 + 12 + 24 + 10 = 54 км. По категориям в алфавитном порядке получаются велосипедный — 24 км, водный — 10 км, пеший — 20 км.

## Путь записи для защиты

`main.py` собирает и проверяет ввод. `logic.add_record()` создаёт словарь со следующим ID и начальным статусом `False`. `storage.save_records()` записывает JSON во временный файл рядом с целевым и заменяет `data.json` после завершения записи. При следующем запуске `storage.load_records()` читает файл и проверяет структуру всего набора. В меню маршруты отображаются по возрастанию ID.
