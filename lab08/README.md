# Лабораторная работа № 8. Словари, множества и кортежи

Вариант 8 — туристические маршруты. Поле `amount` хранит целое число километров. Для демонстрации использованы пять учебных записей в трёх категориях.

## Запуск

Откройте терминал в папке `lab08`. В Windows вместо `python3` можно использовать `py`.

| Команда | Назначение |
| --- | --- |
| `python3 collections_lab.py` | Запустить демонстрацию всех заданий |
| `python3 test_collections.py` | Выполнить автоматические проверки |

Для демонстрации введите текст, темы первого студента через пробел, темы второго студента через пробел и категорию маршрута. Темы вводятся в нижнем регистре. Категории маршрутов — `велосипедный`, `водный`, `пеший`.

## Проверки

Все 20 проверок с `assert` прошли на Python 3.12.14. Также проверены два запуска с вводом и импорт модуля без запуска интерактивной части.

| --- | --- | --- | --- |

## Пояснения к защите

- Словарь связывает ключи со значениями. В записи маршрута поля `title`, `category` и `amount` можно читать по именам. В счётчике слов выражение `counts.get(word, 0)` возвращает сохранённую частоту или ноль при первом появлении слова. Затем присваивание записывает увеличенное значение.
- Множество убирает повторы. Пересечение даёт темы обоих студентов, объединение — все уникальные темы. `sorted()` преобразует результат в упорядоченный список, поскольку порядок вывода множества не гарантирован.
- Кортеж хранит два значения в фиксированном порядке. Его можно распаковать в переменные `title` и `hours`. Список подходит для набора маршрутов, поскольку порядок записей важен при поиске.
- В дополнительном задании ключ сортировки `(-сумма, категория)` задаёт убывание суммы и алфавитный порядок категорий с равной суммой.
