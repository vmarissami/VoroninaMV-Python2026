## Запуск

Откройте терминал в папке `lab02`. Запустите нужную программу и вводите каждое значение отдельной строкой. В Windows вместо `python3` можно использовать `py`. Дробный радиус вводится через точку.

| Команда | Назначение |
| --- | --- |
| `python3 time_parts.py` | Перевести секунды в часы, минуты и секунды |
| `python3 purchase.py` | Рассчитать стоимость тетрадей и сдачу в целых рублях |
| `python3 variant.py` | Рассчитать полные комплекты, остаток заданий и минимальное число комплектов |
| `python3 circle.py` | Рассчитать длину окружности и площадь круга (дополнительное задание) |

## Прогнозы до запуска

| Выражение | Ручной расчёт | Прогноз | Результат Python |
| --- | --- | ---: | ---: |
| `2 + 3 * 4` | Сначала 3 × 4 = 12, затем 2 + 12 | 14 | 14 |
| `(2 + 3) * 4` | Сначала 2 + 3 = 5, затем 5 × 4 | 20 | 20 |
| `17 // 5` | В 17 помещаются три полные пятёрки | 3 | 3 |
| `17 % 5` | После трёх полных пятёрок остаётся 17 − 15 | 2 | 2 |
| `-7 // 2` | −7 / 2 = −3,5. Округление вниз даёт −4 | −4 | −4 |

Все прогнозы совпали с результатами Python.

## Пояснения к защите

- Оператор `/` выполняет обычное деление, например `7 / 2` даёт `3.5`. Оператор `//` округляет частное вниз, поэтому `7 // 2` даёт `3`, а `-7 // 2` даёт `-4`.
- При делении на положительную вместимость `total % capacity` показывает, сколько заданий осталось после заполнения полных комплектов. Для 21 задания и вместимости 10 получается два полных комплекта и одно оставшееся задание. Формула `(21 + 10 - 1) // 10` даёт три комплекта для размещения всех заданий. При нуле заданий формула даёт ноль.
- `float` хранит многие дроби приближённо. Формат `:.2f` округляет число только при выводе, поэтому ошибка представления может сохраняться в дальнейших вычислениях. В `purchase.py` денежные значения хранятся в целых рублях.
